# QMatch 프로젝트 문서

> 게임 플레이어를 위한 실시간 매칭·커뮤니케이션 데스크톱 플랫폼 — 2025 유한대학교 졸업작품

이 폴더는 소프트웨어 개발 7단계(문제정의 → 요구사항 → 설계 → 구조생성 → 구현 → 테스트 → 수정 및 문서화)에 따라 QMatch의 산출물을 정리한 문서입니다. 모든 내용은 `main` 브랜치 소스 코드(백엔드 `qmatch-0.0.23`, 프론트 `0.0.6`)와 git 이력을 기준으로 작성했습니다.

| 단계 | 문서 | 주요 산출물 | UML |
|:--:|---|---|---|
| 1 | [01-문제정의](01-문제정의.md) | 문제 정의서, 목표·KPI, 범위 정의서 | Activity |
| 2 | [02-요구사항](02-요구사항.md) | 사용자 스토리, MoSCoW, SRS, 용어 사전 | Use Case |
| 3 | [03-설계](03-설계.md) | ERD, API 명세서, WebSocket 명세, 화면 설계 | Sequence, Class |
| 4 | [04-구조생성](04-구조생성.md) | 아키텍처 정의서, 기술 스택, 코딩 규칙, 브랜치 전략 | Component, Deployment |
| 5 | [05-구현](05-구현.md) | 패키지 구조, 핵심 로직, 빌드·배포 스크립트 | State |
| 6 | [06-테스트](06-테스트.md) | 테스트 케이스(TC), 결함 리포트, 성능(부하) 테스트 | Communication |
| 7 | [07-수정및문서화](07-수정및문서화.md) | 운영자 매뉴얼, 런북, 개선 백로그 | Package |

## 표기 규칙

- 다이어그램은 모두 [Mermaid](https://mermaid.js.org/)로 작성되어 GitHub에서 바로 렌더링됩니다.
- 엔드포인트·필드·상태값은 코드에서 그대로 옮겼으므로, 코드를 수정하면 문서도 같이 고쳐 주세요.
